# 一、逗号表达式


## 1. 什么是逗号表达式


逗号表达式：

> 使用逗号连接多个表达式。


形式：

```c
exp1, exp2, exp3, ... expN
```


特点：

- 从左到右依次执行
- 整个表达式的结果是最后一个表达式的结果


例如：

```c
int c;

c = (a > b, a = b + 12, a, b = a + 2);
```


执行顺序：

```text
1. 判断 a>b

2. a=b+12

3. 返回a

4. b=a+2

最终整个表达式结果为 b=a+2 的结果
```


---

## 2. 逗号表达式在循环中的应用


例如：

```c
for(a=1,b=2; a<=5 && b<8; a+=2,b++)
{
    printf("a=%d,b=%d\n",a,b);
}
```


作用：

可以在循环初始化和调整阶段同时操作多个变量。

# 二、结构体


## 1. 为什么需要结构体


之前学习的数据类型：

```text
int
float
char
```


一次只能存储一种类型的数据。


但是现实中的一个对象通常包含多个不同类型的信息。


例如学生：

```text
姓名
年龄
成绩
```


所以需要结构体。


---

# 2. 结构体定义


结构体：

> 将多个不同类型的数据组合成一个整体。


格式：

```c
struct 结构体名
{

};
```


例如：

```c
struct student
{
    char name[20];

    int age;

    float score;
};
```


其中：

```text
student
```

相当于创建了一张数据模板。


---

# 3. 创建结构体变量


方式：

```c
struct student s1;
```


此时：

`s1`拥有：

```text
name

age

score
```


三个成员。


---

# 4. 结构体初始化


普通初始化：

```c
struct student s1 = {"James",23,94.0f};
```


指定成员初始化：

```c
struct student s2 =
{
    .name="cacy",
    .age=12,
    .score=12.5f
};
```


---

# 5. 结构体成员访问


使用：

```c
.
```


例如：

```c
printf("%s",s1.name);
```


修改成员：

```c
s1.age=123;
```


---

# 6. 结构体嵌套


结构体里面可以放另一个结构体。


例如：

```c
struct test
{
    char n[20];

    struct student s;

    int sum;
};
```


访问：

```c
t.s.name

t.s.age
```


理解：

> 像打开字典一样，一层一层访问。

# 三、操作符属性


C语言操作符有两个重要属性：

## 1. 优先级


决定：

> 哪个操作符先计算。


例如：

数学：

```text
乘除优先于加减
```


C语言也是类似规则。


---

## 2. 结合性


当多个操作符优先级相同时：

决定计算方向。


例如：

```c
a+b+c
```


按照：

```text
(a+b)+c
```


从左向右计算。

# 五、整型提升


## 1. 什么是整型提升


C语言中：

较小的数据类型参与计算时：

会先转换成 `int` 类型进行计算。


例如：

```c
char a=10;

char b=20;

char c=a+b;
```


---

## 2. char类型


char：

```text
1字节
8个bit
```


范围：

```text
-128 ~ 127
```


例如：

```c
char a=10;
```


二进制：

```text
00001010
```


进行计算时：

会提升为：

```text
00000000 00000000 00000000 00001010
```


也就是：

```text
int类型
```


---

## 3. 整型提升过程


代码：

```c
char c;

c=a+b;
```


过程：


a：

```text
char
↓
int
```


b：

```text
char
↓
int
```


计算：

```text
int + int
```


最后：

结果再转换回：

```text
char
```

# 七、算术转换


## 1. 什么是算术转换


不同类型的数据进行计算时：

会向更大的类型转换。


例如：

```c
int

float
```

计算：

```text
int → float
```


---

## 2. 类型转换等级


从高到低：

```text
long double

↓

double

↓

float

↓

unsigned long int

↓

long int

↓

unsigned int

↓

int
```


规则：

> 类型不同参与运算时，低类型向高类型转换。
